# Rights and scope

The MIT license applies to the original analysis and verification code in
`analysis/` and the original figure-generation code in
`figures/build_prisma_figure.py`. Literature-derived aggregate values, bibliographic fields,
registry identifiers, reporting standards, and any external materials retain
their original attribution and applicable rights. The code license does not
grant rights in those materials. Attribute both the original study and this
review when reusing an extracted value.

The data here are a review-authored projection. They contain aggregate
reported or derived study results, title metadata, counts, and review
categories. There are no participant-level records, database export files,
licensed source texts, correspondence, signed forms, or reviewer receipts.
Queries are supplied as search methods. The exact database result sets depend
on database access, indexing and search date.
