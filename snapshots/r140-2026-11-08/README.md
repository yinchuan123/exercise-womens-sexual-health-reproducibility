# R140 actual source adoption process snapshot

8 November 2026. Three actual author adoption receipts were verified against
their frozen six-question specification and role-specific source vectors.
They contain 18 top-level choices and 415 source actions per author (1,245
actual action cells). All three selecting option A did not mean agreement
on all nested actions: 49 source-action differences remain preserved.

The applied procedure retained the two reviewers' agreed actions, using the
named adjudicator's actual action for 22 differences. The adjudicator's 27
dissents to agreed reviewer actions were retained. No discussion or planned

of separate AI recommendations. Private author receipts are not distributed.

## Source actions and accounting

The 415 applied actions comprise 354 own non-result/nonrandom source closures,
25 own population or bodily-task scope closures, 26 companion/plan/process
uses, five limited whole-package narrative uses and five retained specific
qualification gates. Only the current own-source record route is closed;
parent trials, separate reports and useful references remain preserved.
Missing N, SD, precision or unavailable source text did not themselves cause
a clinical exclusion. A null randomized contrast remains a reportable result.

The 379 new current own-record closures give working routes of 18,835 record
exclusions, 2,487 author-retained routes, 345 technical routes and 288 explicit
HOLD routes. These sum to 21,955 canonical record groups. The frame remains
29,490 identified representations minus 7,535 duplicates. Working routes are
not finalized sequential PRISMA stages. The earlier 99-report/98-source-family
anchor is not an updated whole-search independent census. Other clinical,
registry, family and resource gates remain. No new model inputs, fits or
GRADE decisions were released by these source-use adoptions.

## Reproduce these public checks

Run `python3 snapshots/r140-2026-11-08/verify_snapshot.py` with Python 3.10+.
It checks file hashes, aggregate arithmetic and release boundaries. It cannot
verify private author signatures or reproduce licensed original-source reading.
Authorized project users may regenerate the same whitelist with
`export_from_private_project.py --project /path/to/project --output /tmp/r140.json`.

Historical model data remain frozen at v0.1.0; their command is
`python3 analysis/reproduce.py --output out`. Three restricted comparisons and
six evaluations are separate from 22 diagnostic fits. This process update is
not a manuscript, preprint or journal submission. No source abstracts, raw
