# R222 source-bound analysis and certainty update

This incremental snapshot publishes aggregate numerical data and executable
methods following actual adoption of five new analysis-use questions (one
nonblocking display difference retained) and eleven new exact GRADE targets.
It does not publish personal returns, their fingerprints, contacts, licensed
originals, proprietary search exports, page images, or the unpublished report.

The three locks contain 8+30+1=39 overlapping input sets. Each set has one
family per contrast/outcome/time. There are 78 REML-modified-Hartung-Knapp and
common-effect views; 54 Bayesian prior views consist of 51 fresh Stan MCMC
fits and 3 deterministic integrations. View counts and K/N are never added
across overlapping sets or domains. Original conditional/late/active-background
sets remain explicitly labelled; model computation does not establish clinical
poolability. Inclusive14 retains all ordinary-CI13 sources plus Basgol once;
13 is its without-Basgol reference, not the complete inclusive broad scope.

N layers are source denominator checksums with coverage, not unique women or
pooled effective N. Selected-contrast, mother-trial allocation, observed,
imputed and model populations differ. Source identifiers/hashes and page/table
locators link licensed carriers without distributing them. No unpublished
participant-level data are present.

## Replay

Run verify_snapshot.py for hashes, membership, counts, new-grade adoption and
privacy boundaries. It is offline and does not authenticate signatures or
complete the planned whole-review duplicate original reading.

Run analysis/reproduce_frequentist.R OUTPUT_DIRECTORY to reproduce all78 fits
and all45 leave-one-family-out checks using jsonlite and metafor. Run
analysis/reproduce_deterministic.py --output OUTPUT_DIRECTORY for conditional
normal-mixture Bayesian integration. Run analysis/reproduce_mcmc.R
OUTPUT_DIRECTORY for the actual51 four-chain fits; this compiles the included
actual Stan model rather than requiring a private compiled object. It requires
R, rstan, posterior and a working C++ toolchain and can take substantial time.
Floating-point/compiler and sampler differences require numerical/MCSE-aware
comparison, not byte-identical posterior summaries. No public script fetches
new source material, changes eligibility, generates author votes, or submits
the manuscript. Conditional network replay is a separate optional script.

The pain network has3 trials/4 nodes/3 edges and no residual replication or
closed loop. It is only an explicit-assumption stress test, no ranking/SUCRA,
no clinical transitivity certification and no transferred GRADE. Dose maps
describe planned prescriptions and reported adherence; no optimal duration
or dose-response effect was identified.
